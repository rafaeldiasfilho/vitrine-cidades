# Vitrine (nome provisório)

Vitrine dos comércios de cidades pequenas em um só lugar: lanchonetes, comida caseira, sorveterias e farmácias, com a farmácia de plantão do dia e comparação de preços.

Este repositório tem o **protótipo clicável** usado para validar a ideia com comerciantes. Ainda não é o produto.

**Abrir o protótipo:** https://rafaeldiasfilho.github.io/vitrine-cidades/

> Todos os comércios, preços e telefones são **fictícios**.

## O que o protótipo mostra
- Início com a farmácia de plantão do dia, categorias, comércios abertos agora e destaques
- Cardápio com adicionais, observação, produtos sob encomenda e esgotados
- Carrinho e mensagem de pedido pronta para o WhatsApp do comércio
- Escala de plantão calculada automaticamente
- Busca com comparação de preço entre farmácias

## Rodar localmente
Dois cliques em `prototype/index.html`. Não precisa instalar nada.

## Testes
Precisa do Node.js 18 ou mais novo.

```bash
cd prototype
node --test tests
```
